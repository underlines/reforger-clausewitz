## 2. Does CLW_Arland include them? Recommendation
No (section 0). Runtime registration is not possible: `FactionManager` has only getters (`GetFactionByKey/Index`, `GetFactionsList`, [API]); the faction list is prefab data. Candidate ways:
1. Faction list from the manager only (`GetFactionsList`) after making the world's manager a child of `FactionManager_Editor.et`: picks up every pack that patches it. RHS: yes [SRC]. WCS: n/a (no factions). Other packs: [hyp] most register there so Game Master can use them.
2. A data-only compat addon per pack (`Clausewitz - RHS`, depends on RHS + Clausewitz) that overrides OUR manager prefab with the pack factions: needs a hard dep only in that small addon.
3. Runtime enumeration of `Configs/Factions/*.conf` and injecting `SCR_Faction` into the manager: [hyp], replication/init order, protected arrays: reject.
**Recommend 1 (+2 as fallback).** Create `Prefabs/Managers/CLW_FactionManager.et` and `CLW_LoadoutManager.et` in our addon as children of `FactionManager_Editor.et` / `LoadoutManager_Editor.et`, place those in `CLW_Arland.ent` instead of the USxUSSR ones. Then US, USSR, FIA (+CIV) and any pack-merged factions exist, each with at least a Rifleman loadout; the host picks A/B from `GetFactionsList` minus CIV. Notes:
- All entries are `m_bIsPlayable 0` in the Editor manager; set the chosen A/B at runtime with `SCR_Faction.InitFactionIsPlayable(true)` [API] (or override entries in our child prefab for the vanilla three).
- Hostility: RHS_USAF lists `US` as friendly, RHS_AFRF lists `USSR`; picking RHS_USAF vs US would be friendly. Force with `SCR_FactionManager.SetFactionsHostile(a, b, -1, true)` [API: replicated if called on server].
- Inherit the vanilla `.et` by `{GUID}` and keep our CIV/unused entries; verify the merge in Workbench with `GetFactionsCount()` logs (RHS loaded: expect 4 vanilla + 3 RHS).

## 3. Player spawning for a selected faction
- Needed: (a) faction exists in the manager, (b) at least one `SCR_FactionPlayerLoadout` with `m_sAffiliatedFaction == key` in the world's `SCR_LoadoutManager`, (c) `SCR_SpawnPoint` with that faction key, (d) the spawn logic forced to the faction.
- Loadouts: with `LoadoutManager_Editor.et` as base, RHS already contributes one Rifleman loadout per faction (section 1.1). More roles: reference RHS role confs (`Configs/Loadouts/USAF/USMC/MEF/Loadout_USAF_*.conf`) only in a compat addon.
- Generic runtime alternative [hyp]: `SCR_LoadoutManager.GetPlayerLoadouts()` returns the live `m_aPlayerLoadouts` array [SRC, SCR_LoadoutManager.c]; `SCR_FactionPlayerLoadout` has public `m_sAffiliatedFaction`, `m_sLoadoutName`, `m_sLoadoutResource` [API]. A mod could `Insert(new SCR_FactionPlayerLoadout)` built from the faction's CHARACTER catalog (rifleman-like entry) on server AND clients in the same order (loadouts are replicated by INDEX), at game start before any player requests. No add-API exists. Untested: use only if option above is not enough.
- `SCR_PlayerArsenalLoadout` entries (also in the Editor manager) inherit `SCR_FactionPlayerLoadout` and are returned by `GetPlayerLoadoutsByFaction`; `IsLoadoutAvailable(playerId)` gates them (they need a saved arsenal loadout). [hyp] random/auto selection may skip or pick them: confirm, else drop them in our child prefab.
- Spawn points: `SCR_SpawnPoint.SetFactionKey(string)` is public [API] and `SpawnPoint_Base.et` takes `m_sFaction` (`SpawnPoint_US.et`: `m_sFaction "US"`, [SRC]). Generic: spawn `SpawnPoint_Base`-derived prefab and call `SetFactionKey(chosenKey)` (our `CLW_Bases` already spawns by prefab; switch to one neutral prefab + key). RHS ships its own `SpawnPoint_MSV_CP.et` (`RHS_AFRF`) but no need.
- Forced faction: `SCR_AutoSpawnLogic.m_sForcedFaction` / `GetForcedFaction()` are protected [API]; `modded class SCR_AutoSpawnLogic` override `GetForcedFaction` to return our chosen faction (or keep using `CLW_PlayerSquad.Join` as per project rule).
- WCS_Core extra gates (only if WCS_Core loaded): modded `SCR_PlayerFactionAffiliationComponent.CanRequestFaction_S` (player-limit, optional whitelist, team balancer) [SRC]; with defaults (no limit, whitelist off by default) harmless.
